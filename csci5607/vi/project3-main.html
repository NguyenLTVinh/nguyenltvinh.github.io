Tổng Quan Dự Án

Bạn có thể tải mã nguồn của dự án này tại đây!

Dự án này yêu cầu khối lượng công việc khá lớn và phức tạp. Phần lớn các tính năng cần thiết đã được viết trong Bài Tập 3, vì vậy tôi bắt đầu dự án này dựa trên mã nguồn đã nộp của bài đó. Việc mở rộng để phân tích thêm các tham số như vật liệu và các loại ánh sáng khác nhau khá đơn giản khi sử dụng các cấu trúc (struct) cơ bản. Tôi lưu toàn bộ nguồn sáng và hình cầu trong các vector để hỗ trợ nhiều đối tượng và nguồn sáng. Mặc dù việc bao gói các vector này trong một struct Scene sẽ gọn gàng hơn, nhưng tôi đã không thực hiện điều đó.

Tôi dựa trên pseudocode được cung cấp trong slide bài giảng để xây dựng ray tracer của mình. Việc lập trình chủ yếu tuân theo logic từ pseudocode này: 


Color EvaluateRayTree(Scene scene, Ray ray){
  boolean hit_something;
  HitInformation hit; // struct chứa điểm va chạm, pháp tuyến, v.v.
  hit_something = FindIntersection(scene, ray, &hit);
  if (hit_something){
    return ApplyLightingModel(ray, hit);
  }else{
    return BackgroundColor;
  }
}

Color ApplyLightingModel(Scene scene, Ray ray, HitInformation hit){
  Color contribution = black;
  for each light L:
    Ray shadow(hit.pos, L.pos - hit.pos);
    HitInformation shadow_hit;
    bool blocked = FindIntersection(scene, shadow, &shadow_hit);
    if blocked && shadow_hit.t < Distance(L.pos, hit.pos):
      continue; // nằm trong bóng, chuyển sang nguồn sáng tiếp theo
    contribution += DiffuseContribution(L, hit);
    contribution += SpecularContribtion(L, ray, hit);
  Ray mirror = Reflect(ray, hit.normal);
  contribution += Kr * EvaluateRayTree(scene, mirror);
  Ray glass = Refract(ray, hit.normal);
  contribution += Kt * EvaluateRayTree(scene, glass);
  contribution += Ambient(); // phần bù ambient
  contribution += Emission(hit); // dùng cho nguồn sáng diện tích
}

Tôi bắt đầu bằng việc viết các hàm phụ để tính màu sáng môi trường (ambient), màu sáng khuếch tán (diffuse) và màu sáng phản chiếu (specular). Trong hàm applyLightingModel, tôi khởi tạo màu đen làm giá trị ban đầu. Sau đó, tôi lập trình vòng lặp duyệt qua tất cả các nguồn sáng trong vector và tính hệ số suy giảm (attenuation) của từng nguồn. Trong vòng lặp này, các điểm bị che bóng được phát hiện và giữ nguyên màu đen. Các thành phần diffuse và specular được tính toán và cộng vào tổng màu theo công thức: contribution += attenuation * (diff + spec). Sau vòng lặp nguồn sáng, tôi thêm màu ambient.

Phần khó nhất là lập trình ray tracer đệ quy cho phản xạ và khúc xạ. Tôi đã viết các hàm trợ giúp reflect() và refract(), sau đó làm theo pseudocode của evaluateRayTree. Việc khúc xạ đúng hướng mất khá nhiều lần thử nghiệm. Ban đầu, hình ảnh xuất hiện các vòng tròn lạ quanh phản xạ và độ trong suốt cao hơn so với mẫu. Nguyên nhân là tôi chưa tính đến việc đổi hướng tia khi rời khỏi vật liệu. Khi sửa lại phần này, kết quả đã chính xác hơn rất nhiều.

Dưới đây là các tính năng đã triển khai (bao gồm cả phần bắt buộc và mở rộng). Các tính năng mở rộng được đánh dấu màu hồng, kèm theo mô tả ngắn về cách chúng được thực hiện.

Toán Học

Giao nhau giữa tia và hình cầu

Tôi đã chỉnh sửa lại hàm được cung cấp để trả về giá trị t phục vụ việc tính khu vực đổ bóng. Nếu t dương và nhỏ hơn khoảng cách đến nguồn sáng, nghĩa là có vật thể khác chắn giữa.

Để xác định tia có giao với hình cầu hay không, ta giải phương trình cho tia \(\mathbf{R}(t) = \mathbf{O} + t \mathbf{D}\) và hình cầu bán kính \(r\) tâm tại \(\mathbf{C}\):

\[ \|\mathbf{O} + t\mathbf{D} - \mathbf{C}\|^2 = r^2 \]

Mở rộng ra phương trình bậc hai theo \(t\):

\[ a t^2 + b t + c = 0 \]

với

\[ a = \mathbf{D} \cdot \mathbf{D}, \quad b = 2 (\mathbf{D} \cdot (\mathbf{O} - \mathbf{C})) \] \[ c = (\mathbf{O} - \mathbf{C}) \cdot (\mathbf{O} - \mathbf{C}) - r^2 \]

Nếu \(b^2 - 4ac < 0\), tia không giao với hình cầu.


float intersectSphere(Point3D &rayOrigin, Dir3D &rayDir, Point3D &center,
                      float radius) {
  Dir3D L = Dir3D(rayOrigin.x - center.x, rayOrigin.y - center.y,
                  rayOrigin.z - center.z);
  float a = dot(rayDir, rayDir);
  float b = 2.0f * dot(rayDir, L);
  float c = dot(L, L) - radius * radius;
  float discr = b * b - 4 * a * c;
  if (discr < 0.0f)
    return -1.0f;
  float sqrtD = sqrtf(discr);
  float t0 = (-b - sqrtD) / (2.0f * a);
  float t1 = (-b + sqrtD) / (2.0f * a);
  float t = -1.0f;
  if (t0 > EPSILON)
    t = t0;
  else if (t1 > EPSILON)
    t = t1;
  return t;
}

Ánh sáng và các loại nguồn sáng

Trong ray tracing, ta tính đóng góp ánh sáng từ từng nguồn sáng trong cảnh. Mỗi vòng lặp duyệt qua tất cả các nguồn sáng và xác định hướng, khoảng cách cùng hệ số suy giảm tùy theo loại nguồn sáng.

Nguồn sáng hướng

Nguồn sáng hướng mô phỏng nguồn sáng ở vô cực (như ánh sáng mặt trời). Hướng ánh sáng là ngược lại với vector hướng của nguồn sáng:

\[ \mathbf{L}_{dir} = -\hat{\mathbf{L}}_{dir} \]

Nguồn sáng điểm

Nguồn sáng điểm phát sáng từ một vị trí duy nhất. Hướng ánh sáng là vector từ điểm va chạm đến nguồn sáng, và cường độ giảm theo luật nghịch đảo bình phương khoảng cách:

\[ \mathbf{L}_{dir} = \frac{\mathbf{L}_{pos} - \mathbf{P}_{hit}}{\|\mathbf{L}_{pos} - \mathbf{P}_{hit}\|}\] \[attenuation = \frac{1}{\|\mathbf{L}_{pos} - \mathbf{P}_{hit}\|^2} \]

Nguồn sáng chiếu điểm

Nguồn sáng chiếu điểm (spotlight) tương tự nguồn sáng điểm nhưng chỉ chiếu sáng trong một hình nón. Hướng và hệ số suy giảm được tính như nguồn sáng điểm, nhưng thêm điều kiện góc giữa hướng trung tâm và hướng đến điểm va chạm:

\[ \cos\theta = \hat{\mathbf{L}}_{spot} \cdot \frac{\mathbf{P}_{hit} - \mathbf{L}_{pos}}{\|\mathbf{P}_{hit} - \mathbf{L}_{pos}\|}\] \[attenuation *= f(\theta) \]

Hàm \(f(\theta)\) mô tả độ giảm sáng theo góc: - Nếu \(\theta > \theta_2\), điểm nằm ngoài vùng chiếu → không có ánh sáng. - Nếu \(\theta_1 < \theta \le \theta_2\), ánh sáng giảm dần tuyến tính giữa nón trong và nón ngoài. 


for (Light &L : lights) {
    Dir3D Ldir;
    float attenuation = 1.0f;
    float maxLightDist = 1e30f;

    if (L.type == DIRECTIONAL_LIGHT) {
        Ldir = L.dir.normalized() * -1.0f;
    } else if (L.type == POINT_LIGHT) {
        Dir3D tmp = L.pos - hitPoint;
        float dist2 = tmp.magnitudeSqr();
        maxLightDist = sqrtf(dist2);
        if (maxLightDist > 0.0f)
            Ldir = tmp.normalized();
        else
            continue;
        attenuation = 1.0f / dist2;
    } else if (L.type == SPOT_LIGHT) {
        Dir3D tmp = L.pos - hitPoint;
        float dist2 = tmp.magnitudeSqr();
        maxLightDist = sqrtf(dist2);
        if (maxLightDist > 0.0f)
            Ldir = tmp.normalized();
        else
            continue;
        attenuation = 1.0f / dist2;

        Dir3D spotToPoint = (hitPoint - L.pos).normalized();
        float cosAngle = dot(spotToPoint, L.dir.normalized());
        float ang = acosf(clamp(cosAngle, 0.0f, 1.0f)) * (180.0f / M_PI);
        if (ang > L.angle2) continue;
        else if (ang > L.angle1) {
            float tfall = (ang - L.angle1) / (L.angle2 - L.angle1);
            attenuation *= (1.0f - tfall);
        }
    }
}

Ánh sáng khuếch tán (Lambert)

Thành phần khuếch tán tỉ lệ với cosin của góc giữa hướng sáng \(\mathbf{L}\) và pháp tuyến bề mặt \(\mathbf{N}\):

\[ C_\text{diffuse} = k_d (\mathbf{L} \cdot \mathbf{N}) \mathbf{I}_L \]


Color diffuseContribution(Light &L, Dir3D &N, Material &m, Dir3D &Ldir) {
  float NdotL = std::max(dot(N, Ldir), 0.0f);
  return Color(m.dr * NdotL * L.intensity.r, m.dg * NdotL * L.intensity.g,
               m.db * NdotL * L.intensity.b);
}

Ánh sáng phản chiếu (Phong)

Thành phần phản chiếu được xác định bằng góc giữa vector phản xạ \(\mathbf{R}\) và hướng nhìn \(\mathbf{V}\):

\[ C_\text{specular} = k_s (\mathbf{R} \cdot \mathbf{V})^n \mathbf{I}_L \] 


Color specularContribution(Light &L, Dir3D &N, Dir3D &V, Material &m,
                           Dir3D &Ldir) {
  Dir3D negLdir = Ldir * -1.0f;
  Dir3D R = reflect(negLdir, N);
  float RdotV = std::max(dot(R, V), 0.0f);
  float specFactor = (m.ns > 0.0f) ? powf(RdotV, m.ns) : 0.0f;
  return Color(m.sr * specFactor * L.intensity.r,
               m.sg * specFactor * L.intensity.g,
               m.sb * specFactor * L.intensity.b);
}

Đổ bóng

Khu vực đổ bóng được tính bằng cách bắn một tia từ điểm va chạm đến nguồn sáng. Nếu tia này bị chặn trước khi đến nguồn sáng, điểm đó nằm trong bóng tối. 


Point3D shadowOrigin = hitPoint + N * EPSILON;
bool blocked = false;
for (Sphere &s : spheres) {
    float t = intersectSphere(shadowOrigin, Ldir, s.center, s.radius);
    if (t > 0.0f && t < maxLightDist - EPSILON) {
    blocked = true;
    break;
    }
}
if (blocked)
    continue;

Phản xạ

Hướng phản xạ của tia tới \(\mathbf{I}\) tại bề mặt có pháp tuyến \(\mathbf{N}\) được tính bằng công thức:

\[ \mathbf{R} = \mathbf{I} - 2 (\mathbf{I} \cdot \mathbf{N}) \mathbf{N} \]

Đây là cơ sở cho thành phần phản chiếu trong mô hình Phong, nơi vùng sáng phụ thuộc vào góc giữa \(\mathbf{R}\) và hướng nhìn \(\mathbf{V}\). 


Dir3D reflect(Dir3D &I, Dir3D &N) {
  float dotIN = dot(I, N);
  Dir3D scaledNormal = 2.0f * dotIN * N;
  return I - scaledNormal;
}

Khúc xạ (định luật Snell)

Khúc xạ được tính dựa trên định luật Snell:

\[ n_i \sin \theta_i = n_r \sin \theta_r \]

Dưới dạng vector, nếu \(\mathbf{I}\) là tia tới và \(\mathbf{N}\) là pháp tuyến:

\[ \mathbf{T} = \eta \mathbf{I} + (\eta \cos\theta_i - \cos\theta_r) \mathbf{N} \]

với \(\eta = n_i / n_r\), \(\cos\theta_i = -\mathbf{I} \cdot \mathbf{N}\), và \(\cos\theta_r = \sqrt{1 - \eta^2 (1 - \cos^2 \theta_i)}\). Nếu phần căn bậc hai âm, xảy ra phản xạ toàn phần.

Dựa vào dấu của \(\cos\theta_i\), ta xác định tia đang đi vào hay đi ra khỏi vật thể. Nếu đi ra, cần đảo ngược pháp tuyến và hoán đổi chỉ số khúc xạ để tia khúc xạ được tính đúng hướng. 


Dir3D refract(Dir3D &I, Dir3D &N, float ior) {
  Dir3D I_norm = I.normalized();
  float cosi = clamp(dot(I_norm, N), -1.0f, 1.0f);
  float nui = 1, nur = ior;
  Dir3D n = N;

  if (cosi < 0) {
    cosi = -cosi;
  } else {
    std::swap(nui, nur);
    n = N * -1.0f;
  }

  float nu = nui / nur;
  float k = 1 - nu * nu * (1 - cosi * cosi);
  if (k < 0)
    return Dir3D(0, 0, 0);

  return (nu * I_norm + (nu * cosi - sqrtf(k)) * n).normalized();
}
