This project required a considerable amount of work and is quite complex. Most of the required features were constructed in Assignment 3, so I started with my submitted Assignment 3 as the base code. Programming the parsing of extra parameters, such as materials and different types of lights, was relatively simple using basic structs. I also stored all the lights and spheres in vectors to accommodate multiple lights and spheres. Although wrapping these vectors in a Scene struct might have been cleaner, I did not do that.

I used the pseudocode provided in the lecture slides as a basis for building my ray tracer. The implementation largely follows this pseudocode: 


Color EvaluateRayTree(Scene scene, Ray ray){
  boolean hit_somthing;
  HitInformation hit; // structure containing hit point, normal, etc
  hit_something = FindIntersection( scene, ray, &hit );
  if (hit_something){
    return ApplyLightingModel( ray, hit );
  }else{
    return BackgroundColor;
  }
}

Color ApplyLightingModel( Scene scene, Ray ray, HitInformation hit ){
  Color contribution = black;
  for each light L:
    Ray shadow ( hit.pos, L.pos - hit.pos );
    HitInformation shadow_hit;
    bool blocked = FindIntersection( scene, shadow, &shadow_hit );
    if blocked && shadow_hit.t < Distance( L.pos, hit.pos ):
      continue; // we're in shadow, on to the next light;
    contribution += DiffuseContribution( L, hit );
    contribution += SpecularContribtion( L, ray, hit );
  Ray mirror = Reflect( ray, hit.normal );
  contribution += Kr*EvaluateRayTree( scene, mirror )
  Ray glass = Refract( ray, hit.normal );
  contribution += Kt*EvaluateRayTree( scene, glass );
  contribution += Ambient(); // superhack!
  contribution += Emission( hit ); // for area light sources only
}

I began by writing helper functions to calculate ambient, diffuse, and specular colors. In the applyLightingModel function, I started with the color black. Then I wrote a loop to iterate through all lights in the vector and calculate their attenuation. Within this loop, shadow pixels were also detected, and their color remains black. Diffuse and specular contributions are calculated and added to the overall color using the formula contribution += attenuation * (diff + spec). After the light loop, I added the ambient color.

The most challenging part was programming the recursive ray tracer for reflection and refraction. I wrote the helper functions reflect() and refract(), then followed the pseudocode for evaluateRayTree. It took a few attempts to get refraction correct. I encountered some issues with strange circular artifacts on sphere reflections, and transparency was higher than in the example images. It turned out I hadn't accounted for the ray's direction change when leaving the material. Once that was fixed, the results looked correct.

The Maths

Ray-sphere intersection

I refactored the given function to return t for shadow implementation. If t is positive and smaller than the distance to the light, it means another object is blocking the path.

To determine whether a ray intersects a sphere, we solve the equation for a ray \(\mathbf{R}(t) = \mathbf{O} + t \mathbf{D}\) and a sphere of radius \(r\) centered at \(\mathbf{C}\):

\[ \|\mathbf{O} + t\mathbf{D} - \mathbf{C}\|^2 = r^2 \]

Expanding this gives a quadratic in \(t\):

\[ a t^2 + b t + c = 0 \]

where

\[ a = \mathbf{D} \cdot \mathbf{D}, \quad b = 2 (\mathbf{D} \cdot (\mathbf{O} - \mathbf{C})) \] \[ c = (\mathbf{O} - \mathbf{C}) \cdot (\mathbf{O} - \mathbf{C}) - r^2 \]

If \(b^2 - 4ac < 0\), there is no intersection.


float intersectSphere(Point3D &rayOrigin, Dir3D &rayDir, Point3D &center,
                      float radius) {
  Dir3D L = Dir3D(rayOrigin.x - center.x, rayOrigin.y - center.y,
                  rayOrigin.z - center.z);
  // O + t * D
  float a = dot(rayDir, rayDir);
  float b = 2.0f * dot(rayDir, L);
  float c = dot(L, L) - radius * radius;
  float discr = b * b - 4 * a * c;
  if (discr < 0.0f)
    return -1.0f;
  float sqrtD = sqrtf(discr);
  float t0 = (-b - sqrtD) / (2.0f * a);
  float t1 = (-b + sqrtD) / (2.0f * a);
  // smallest positive t
  float t = -1.0f;
  if (t0 > EPSILON)
    t = t0;
  else if (t1 > EPSILON)
    t = t1;
  return t;
}

Lighting and Light Types

In ray tracing, we calculate lighting contributions for each light in the scene. The loop iterates through all lights and computes the direction, distance, and attenuation of the light at the hit point depending on its type:

1. Directional Light

Directional lights simulate a light source at infinity (like sunlight). The light direction is simply the opposite of the light's direction vector:

\[ \mathbf{L}_{dir} = -\hat{\mathbf{L}}_{dir} \]

2. Point Light

Point lights emit light from a single position. The light direction is the vector from the hit point to the light, and intensity attenuates according to the inverse-square law:

\[ \mathbf{L}_{dir} = \frac{\mathbf{L}_{pos} - \mathbf{P}_{hit}}{\|\mathbf{L}_{pos} - \mathbf{P}_{hit}\|}\] \[attenuation = \frac{1}{\|\mathbf{L}_{pos} - \mathbf{P}_{hit}\|^2} \]

3. Spot Light

Spot lights are like point lights but restricted to a cone. The direction and attenuation are computed like point lights, but we also compute the angle between the light's central direction and the vector toward the hit point:

\[ \cos\theta = \hat{\mathbf{L}}_{spot} \cdot \frac{\mathbf{P}_{hit} - \mathbf{L}_{pos}}{\|\mathbf{P}_{hit} - \mathbf{L}_{pos}\|}\]\[attenuation *= f(\theta) \]

Here, \(f(\theta)\) defines the angular falloff: - If \(\theta > \theta_2\), the point is outside the outer cone → no contribution. - If \(\theta_1 < \theta \le \theta_2\), a linear falloff scales the light intensity between the inner and outer cones. 


for (Light &L : lights) {
    Dir3D Ldir;
    float attenuation = 1.0f;
    float maxLightDist = 1e30f;

    if (L.type == DIRECTIONAL_LIGHT) {
        Ldir = L.dir.normalized() * -1.0f;
    } else if (L.type == POINT_LIGHT) {
        Dir3D tmp = L.pos - hitPoint;
        float dist2 = tmp.magnitudeSqr();
        maxLightDist = sqrtf(dist2);
        if (maxLightDist > 0.0f)
            Ldir = tmp.normalized();
        else
            continue;
        attenuation = 1.0f / dist2;
    } else if (L.type == SPOT_LIGHT) {
        Dir3D tmp = L.pos - hitPoint;
        float dist2 = tmp.magnitudeSqr();
        maxLightDist = sqrtf(dist2);
        if (maxLightDist > 0.0f)
            Ldir = tmp.normalized();
        else
            continue;
        attenuation = 1.0f / dist2;

        Dir3D spotToPoint = (hitPoint - L.pos).normalized();
        float cosAngle = dot(spotToPoint, L.dir.normalized());
        float ang = acosf(clamp(cosAngle, 0.0f, 1.0f)) * (180.0f / M_PI);
        if (ang > L.angle2) continue;
        else if (ang > L.angle1) {
            float tfall = (ang - L.angle1) / (L.angle2 - L.angle1);
            attenuation *= (1.0f - tfall);
        }
    }
}

Diffuse lighting (Lambertian)

The diffuse contribution is proportional to the cosine of the angle between the light direction \(\mathbf{L}\) and the surface normal \(\mathbf{N}\):

\[ C_\text{diffuse} = k_d (\mathbf{L} \cdot \mathbf{N}) \mathbf{I}_L \]


Color diffuseContribution(Light &L, Dir3D &N, Material &m, Dir3D &Ldir) {
  float NdotL = std::max(dot(N, Ldir), 0.0f);
  return Color(m.dr * NdotL * L.intensity.r, m.dg * NdotL * L.intensity.g,
               m.db * NdotL * L.intensity.b);
}

Specular lighting (Phong)

Specular highlights are computed using the reflected light vector \(\mathbf{R}\) and the view direction \(\mathbf{V}\):

\[ C_\text{specular} = k_s (\mathbf{R} \cdot \mathbf{V})^n \mathbf{I}_L \] 


Color specularContribution(Light &L, Dir3D &N, Dir3D &V, Material &m,
                           Dir3D &Ldir) {
  Dir3D negLdir = Ldir * -1.0f;
  Dir3D R = reflect(negLdir, N);
  float RdotV = std::max(dot(R, V), 0.0f);
  float specFactor = (m.ns > 0.0f) ? powf(RdotV, m.ns) : 0.0f;
  return Color(m.sr * specFactor * L.intensity.r,
               m.sg * specFactor * L.intensity.g,
               m.sb * specFactor * L.intensity.b);
}

Shadows

Shadows are computed by casting a ray from the hit point toward the light. If any object intersects this ray before the light, the point is in shadow. 


Point3D shadowOrigin = hitPoint + N * EPSILON;
bool blocked = false;
for (Sphere &s : spheres) {
    float t = intersectSphere(shadowOrigin, Ldir, s.center, s.radius);
    if (t > 0.0f && t < maxLightDist - EPSILON) {
    blocked = true;
    break;
    }
}
if (blocked)
    continue;

Reflection (Phong model)

The reflection direction of an incident ray \(\mathbf{I}\) on a surface with normal \(\mathbf{N}\) is computed using vector reflection:

\[ \mathbf{R} = \mathbf{I} - 2 (\mathbf{I} \cdot \mathbf{N}) \mathbf{N} \]

This forms the basis of Phong specular reflection, where highlights are computed based on the angle between \(\mathbf{R}\) and the viewer direction \(\mathbf{V}\). 


Dir3D reflect(Dir3D &I, Dir3D &N) {
  float dotIN = dot(I, N);
  Dir3D scaledNormal = 2.0f * dotIN * N;
  return I - scaledNormal;
}

Refraction (Snell's law)

Refraction is computed using Snell's law:

\[ n_i \sin \theta_i = n_r \sin \theta_r \]

In vector form, if \(\mathbf{I}\) is the incident ray and \(\mathbf{N}\) the normal:

\[ \mathbf{T} = \eta \mathbf{I} + (\eta \cos\theta_i - \cos\theta_r) \mathbf{N} \]

where \(\eta = n_i / n_r\), \(\cos\theta_i = -\mathbf{I} \cdot \mathbf{N}\), and \(\cos\theta_r = \sqrt{1 - \eta^2 (1 - \cos^2 \theta_i)}\). If the square root is negative, total internal reflection occurs.

By checking whether \(\cos\theta_i\) is less than or greater than 0, we can determine if the ray is entering or leaving the object. If it's leaving, it flips the surface normal and swaps the refractive indices so the refraction math bends the ray in the correct direction. 


Dir3D refract(Dir3D &I, Dir3D &N, float ior) {
  Dir3D I_norm = I.normalized();
  float cosi = clamp(dot(I_norm, N), -1.0f, 1.0f);
  float nui = 1, nur = ior;
  Dir3D n = N;

  if (cosi < 0) {
    cosi = -cosi;
  } else {
    std::swap(nui, nur);
    n = N * -1.0f;
  }

  float nu = nui / nur;
  float k = 1 - nu * nu * (1 - cosi * cosi);
  if (k < 0)
    return Dir3D(0, 0, 0);

  return (nu * I_norm + (nu * cosi - sqrtf(k)) * n).normalized();
}
