Why I Use Linux (And Why You Might Want To)

November 26th, 2025

Introduction

I have been using Linux as my main operating system for about 3 years now. If you scroll through my website, you would know that I'm a huge advocate. And I'm not the only one. If you've spent any time around software engineers or in developer forums, you've probably heard people mention Linux with an almost religious fervor. But what is Linux, and why has it garnered such a cult-like following?

What is Linux?

At its core, Linux is an operating system, just like Windows or macOS. It's the fundamental software that manages your computer's hardware and lets you run programs. But here's where Linux differs: it's open source, meaning its underlying code is freely available for anyone to view, modify, and distribute. And since the code is open and available, Linux is fundamentally always free, as in, you don't have to pay for it. This might sound like a small technical detail, but it has profound implications for how the software works and what you can do with it.

Unlike Windows or macOS, which are controlled by single corporations, Linux is developed by a global community of programmers who contribute their time and expertise. This collaborative approach has created something remarkable: an operating system that's incredibly stable, secure, and flexible. Major tech companies like Google, Amazon, and Facebook run their servers on Linux. Android phones use a Linux-based system. Even the International Space Station relies on Linux. If it powers the infrastructure of the modern internet, there's a good chance Linux is involved.

Why do I use Linux?

For starters, you should know that I study Computer Science and will soon enter the workforce as a software engineer. As someone who writes software, Linux isn't just an option for our field. It's practically the native environment. The most immediate advantage is that Linux mirrors the environments where most of our code runs. Whether you're building web applications, managing databases, or deploying services to the cloud, there's a good chance your production environment is running Linux. When you develop on Linux, you eliminate the friction of context switching between different operating systems. What works on your laptop works on your server, and you're not constantly translating between Windows quirks and UNIX conventions. This alignment alone saves countless hours of debugging environment-specific problems.

Most Linux distributions come ready to code right out of the box. Fire up a fresh Ubuntu, Fedora, or Arch installation and you'll find essential development tools already installed: GCC and other compilers, Python, Perl, text editors like Vim or Nano, Git for version control, Make for build automation, and many other utilities for scripting and system interaction. Linux distributions recognize that many users are developers and treat programming tools as fundamental components of the system itself. Within minutes of installation, you can write and compile C code, run Python scripts, manage repositories with Git, and start building projects without downloading a single additional package. Even languages not included by default are typically one package manager command away.

Why YOU should use Linux

So why should you, as an everyday computer user, consider switching to Linux? For starters, it's completely free. Not just cheap, but genuinely free to download, install, and use forever. There are no license fees, no forced upgrades, and no subscription services. You can install it on as many computers as you want without spending a dime. This is especially helpful if you are building a computer yourself, which doesn't come with a pre-installed operating system.

Beyond the price tag, Linux offers something that's increasingly rare in modern computing: control over your own machine. Your computer won't install updates without your permission or restart at inconvenient times. There's no telemetry quietly sending your data back to corporate servers unless you explicitly enable it. You decide what runs on your system, when it runs, and how it behaves. In an era where our devices often feel like they belong more to their manufacturers than to us, this sense of ownership is refreshing.

Linux is also incredibly lightweight and efficient. That old computer you had that is slowing down? It's not the computer. It's Windows pushing new updates that have more overhead and background tasks (which send your usage data to Microsoft). Some older computers that don't even meet the minimum requirements for Windows 11 can run the latest version of any Linux distribution with the latest software while still being incredibly performant and snappy.

Security is another major advantage. While no system is completely immune to threats, Linux's architecture and the transparency of its code make it significantly more resistant to viruses and malware. Most Linux users never install antivirus software because the system's permission structure and the vigilance of the open-source community catch vulnerabilities quickly. When security flaws are discovered, they're typically patched within days rather than weeks or months. Plus, since Linux makes up such a tiny market share, computer viruses tend not to be designed for it, but rather for the most popular operating system: Windows.

Perhaps the most compelling aspect of Linux is its variety and customizability. You can install whatever Linux distribution fits your needs. First-time users usually go for Ubuntu, which has a similar feel to Chromebooks. Former Windows users might find Linux Mint to be the most familiar. Hardcore users will want to choose Arch, which allows a much wider range of customizations. I personally use Fedora, which is stable, maintained by Red Hat, but is still cutting edge. It gets the job done for me. The learning curve is real, but it's gentler than you might think. Modern Linux distributions are remarkably user-friendly, with graphical interfaces that rival anything Windows or macOS offers. You can browse the web, write documents, edit photos, watch videos, and handle everyday tasks without ever touching a command line.

You should NOT use Linux if you are…

Linux isn't for everyone. If I have compelled you to make the switch by now, make sure that you do not belong to one of the user groups below before going out of your way to install a completely new operating system:

1. You have an Apple Silicon M-Series Mac or MacBook

While yes, a Linux distro (Asahi Linux) exists for M-Series Macs, that doesn't mean you should switch to it. Just use your macOS. You spent a ridiculous amount of money on a Mac or MacBook for a reason, and half that reason is macOS itself. It may not be open and freeing like Linux, but it's still a UNIX-based operating system, which is decent for programming and completely fine for regular office work.

2. You play a video game with kernel-level anticheat

While most single-player games and many online games run fine with Proton, and often outperform Windows on Linux, a lot of the online competitive video games have adopted kernel-level anticheat, which is, first of all, pretty much malware. Basically, you are allowing these game companies to run their close-sourced software with the highest level of privilege on your system. Kernel-level anticheat does not work on Linux, and it will never be allowed. Stick to Windows if you want to keep playing Valorant.

3. You are a graphic designer who relies on Adobe's services

While alternative software like GIMP or Inkscape exists, you can't easily escape the industry's standards. Although there are ways to run Photoshop and other Adobe software on Linux, it is quite complicated and not really worth the effort. Stick to Windows or macOS if you must use Adobe's services.

4. You use specialized professional software with no Linux equivalent

Certain industries depend on software that simply doesn't exist on Linux. Video editors who need DaVinci Resolve (which does have a Linux version) are fine, but if you're tied to Final Cut Pro, you're stuck with macOS. Audio engineers using Pro Tools, architects using AutoCAD or Revit, or anyone dependent on industry-specific proprietary software should verify Linux compatibility before making the leap. Running these through compatibility layers often means degraded performance or missing features.

The bottom line is, make sure the software you need runs on Linux or has a viable alternative.

Conclusion

For me, Linux is more than just an operating system. It's a different way of thinking about how you interact with your computer. For developers, it's a powerful native environment. For privacy-conscious users, it's freedom from corporate data collection. For anyone with an old computer gathering dust, it's a chance to make that machine useful again. Sure, there's a learning curve, and it won't work for everyone's needs. But if you're tired of feeling like your computer controls you instead of the other way around, Linux might be worth exploring. The best part? It costs nothing to try. Download a live USB, boot it up, and see if it clicks for you. You might just find that computing can be simpler, faster, and more enjoyable than you thought possible.
