Deep Learning Malware Detection and Classification

Description: This work applies deep learning image recognition to classify malware from executable files using static analysis. A hybrid CNN-ViT model and transfer learning with EfficientNet-B0 achieved higher accuracy than previous methods on the VirusMNIST dataset. The approach outperforms traditional techniques in detecting diverse malware families and benign software.

Semantic 3D Reconstruction and Object Tracking for Transparent Objects

Description: This work presents a pipeline for detecting, tracking, and estimating the 6D poses of transparent objects, which are challenging for traditional 3D reconstruction methods. Unlike AR/VR applications, the focus is on accurate localization for robotic manipulation. The approach supports tasks like robotic grasping, warehouse automation, and assistive robotics.

Technologies Used:

Paper

Early-Childhood Autism Screening

Description: Autism spectrum disorder (ASD) has been researched for decades yet is still notably challenging to diagnose due to considerable heterogeneity within behavioral, genetic, neurological, and physiological profiles. This project applies classical machine learning techniques to classify early likelihood and clinical diagnosis of autism using a comprehensive clinical battery.

Two-factor Authenticated Door Lock

Description: This project implements a two-factor-authenticated door lock system. The system enhances physical security by requiring both an RFID card and a PIN code. It integrates embedded programming, low-level communication protocols, and secure inter-board messaging using microcontrollers.

TuxSay

Description:Inspired by cowsay and fortune, TuxSay is a simple command-line utility that displays messages in an ASCII art speech bubble, optionally using different ASCII art characters. It also has an option to display random Linus Torvalds quotes.
